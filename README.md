တရိပ်ရိပ် မှိုင်းလာတဲ့ မှောင်ရီပျိုးချိန်
ရွာဦးကျောင်းက ခေါင်းလောင်းသံဟာ
ရင်ထဲအထိ တိုးဝင်လို့ လွမ်းရပြန်တယ်။
​အမေချက်တဲ့ ဟင်းအိုးနံ့ သင်းသင်းရယ်
မီးခိုးငွေ့တွေ ဝေမှိုင်းတဲ့ တောရွာလေးညနေ
ကောက်ရိုးပုံဘေးက ခွေးဟောင်သံကအစ
အခုတော့... အိမ်မက်ထဲက ပုံပြင်လိုပါပဲ။
​မြို့ပြရဲ့ မီးရောင်စုံအောက်မှာ
အေးချမ်းတဲ့ ရွာကလေးကို တမ်းတရင်း
ဒီညလည်း... အလွမ်းမိုးတွေ ရွာဦးမယ်။
